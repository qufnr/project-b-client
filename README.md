# Project B Client

사용자와 영상(YouTube, NicoNico 등)과 음악(YouTube, YouTube Music, SoundCloud 등)을 실시간 공유하여 함께 보고 듣는 서비스입니다.  

## Environment
- Node.js 20.19.0
- yarn 1.22.19

## Installation
> yarn install  
> yarn dev || yarn dev:home  

모바일 환경도 접근하려면 `yarn dev:home`으로 실행해요
